# Anon-callable SECURITY DEFINER functions — the surface that RLS audits cannot see.
#
# FORMAT   <function name> | <what ACTUALLY gates it>
# READ BY  tests/db/anon-rpc-surface.db.test.ts (inside a REQUIRED check)
#
# ── WHY THIS FILE EXISTS ────────────────────────────────────────────────────
# A SECURITY DEFINER function runs with the owner's rights and ignores every RLS
# policy on the tables it touches. `anon` means any holder of the publishable
# key that ships in the public JavaScript bundle — no account, no session.
#
# Being on this list is NOT an admission of a bug. This product deliberately
# gates guests on secret tokens rather than sessions: a guest has no account,
# and an unguessable QR or claim token IS the credential. `public_seat_lookup`
# SHOULD be here.
#
# What the guard forbids is a function arriving here SILENTLY. Before adding a
# line, read the body and answer one question:
#
#     What stops an anonymous caller passing arguments of their choosing?
#
# "It is only called from our own server" is NOT an answer. The grant decides
# who may call it, not the caller you had in mind. And note what is NOT a
# credential: an event id, a slug, an email, a sequential id. Event ids appear
# in guest-facing URLs — three functions were closed on 2026-08-01 precisely
# because they treated one as a secret.
#
# ── SEEDED 2026-08-01 ───────────────────────────────────────────────────────
# 211 functions were anon-callable when this file was created. The 33 touching
# sensitive data were read in full and 7 were revoked outright (migration
# 20271028837115) — including one that DELETES chat threads and one that MINTS
# vendor tokens. The rest are seeded below as UNREVIEWED, which is honest: they
# were filtered out as lower-risk by a heuristic, not cleared by a human.
#
# `unreviewed` is a debt marker, exactly like `map-backlog` in
# ugat-concept.baseline.txt. The count should shrink. Replacing one with a real
# reason is the unit of work.
