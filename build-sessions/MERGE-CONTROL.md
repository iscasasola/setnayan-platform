## 🔌 COUPLING — a CLEAN merge that still breaks something

The dangerous case is not a conflict. Candidate A edits a shared module; candidate B never
opens that file but **imports** it, in another route, owned by another session. `merge-tree`
calls that CLEAN and it is, textually — the break is in meaning, and only sequencing prevents it.
