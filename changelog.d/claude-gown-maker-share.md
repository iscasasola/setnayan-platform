No public endpoint, no import link.
- **Shortlist** stores the design and shows a reusable code that rides the shipped Shortlist QR landing (`/{shop}/invite?gown=<code>`, the same `claimVendorInviteToEvent`). **Booked** opens the shipped Booked QR form with the design attached; the code is linked to it (`gown_designs.locked_token`), so every Booked QR refusal and both bookings-closed doors are unchanged. A code that cannot carry its design is withdrawn.
- **Scan.** The shop is added (shortlisted or booked, exactly as today), the design is posted once as a card in that couple-supplier chat (`👗 Gown design · …`, opening the thread if needed), and the couple lands in that chat. The card shows the picture, the summary and the price shown to the client; the supplier side adds Make a quote (prefilled). The tool's `state` never reaches a couple.
