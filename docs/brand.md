# Positioning and marketing rules

> Every session follows this, for every word a person reads: UI, emails, notifications,
> share cards, page titles, meta descriptions, ads, posts. It is imported by `CLAUDE.md`,
> so it loads automatically.
>
> For product facts (what is live, prices, limits) the specs corpus wins. For wording and
> claims this file wins. If they conflict, fix the loser in the same PR.

## Positioning

Setnayan is the home where Filipino events are planned, lived and kept. It is one place
where hosts, guests, suppliers and coordinators all work on the same event, and families
come back to it for every milestone.

- **Pillars:** Plan it · Live it · Keep it.
- **Brand line:** "The home of every Filipino celebration."
- **Tagline:** "Set na 'yan."

## Mission

Elevate the Philippine events industry:

- honest suppliers who are easy to find;
- hosts who plan without fear of scams;
- family memories that last.

## Word rules

| Say | Never say |
|---|---|
| supplier | vendor |
| Event Hub | website, site (except SEO copy: "your wedding website") |
| event | celebration (allowed only in brand lines) |
| E-Gifts | Pabuya |
| Logo Maker | Monogram |
| Articles | Blog, Journal |
| reservation fee | down payment |
| Setnayan, spelled in full | any short form |
| setnayan.com | any other domain |

## Claims never made in UI or marketing copy

1. **A hand-typed price.** Always read the live price table.
2. **The booking fee, shown to hosts or guests.** Host pages may say "0% commission".
3. **Price promises.** Never "free for life", "always free", "first booking free" or free
   months.
   - "Every photo kept for life" about Memories is product truth and allowed.
   - Never imply full-size originals last forever: originals are kept 3/6/12 months by
     plan, then a 720p copy for life.
4. **Badge numbers.**
5. **Hand-typed tool counts.**
6. **Speed claims.**
7. **Supplier testimonials** without the supplier's written permission.
8. **"iPhone app"** before Apple approves it.
9. **Any feature that is coming** and not yet live. Check the list in the specs corpus:
   `MARKETING_RESEARCH_BRIEF_2026-11-24.md` § 3, "COMING (do not advertise yet)".
   Read it with `gh api repos/iscasasola/Setnayan-specs/contents/MARKETING_RESEARCH_BRIEF_2026-11-24.md`
   or `git -C <corpus> show origin/main:MARKETING_RESEARCH_BRIEF_2026-11-24.md`.
10. **Promises:** "safe", "scam-free", "guaranteed", "trusted".
11. **Rank claims:** "first", "#1", "only".
12. **Named competitors.**
13. **"Data Privacy Act compliant"** used as a slogan.

## Tone

- Name the feeling, then delight.
- Lines of about 12 words or fewer.
- Taglish is welcome.
- No pain-point headlines: no "Tired of", "Stop", "No more", "Why choose us",
  "Join now", "Save X%".

## Page order

1. Show it working.
2. Remove the fear.
3. Sell the upgrade.
