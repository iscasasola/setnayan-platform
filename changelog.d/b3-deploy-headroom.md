## 2026-09-10 · fix(deploy): the mood-board server function stops carrying all of public/ — and the Next.js security update can land

- **What broke.** The Next.js 15.5.21 → 15.5.24 security release (#5397) could not deploy: Vercel refused the `vendor-dashboard/clients/[eventId]/mood-board` function at **252.37 MB** against its 250 MB ceiling. Main sat just under it, so any ordinary merge could have stopped every production deploy the same way.
- **Why.** One line in `lib/reception-decor-layers-server.ts` (2026-09-06) rooted a disk read at `path.join(process.cwd(), 'public')`. Next's file tracer reads `readFile(path.resolve(<root>, <anything>))` as "any file under that root", so it copied **951 files · 117 MB** of `public/` — demo films, onboarding clips, Real Story photos — into the function. The code can only ever open `/moodboard-seed/…` files (its href predicate pins that prefix).
- **Fix.** The root is now `public/moodboard-seed/`. Measured with Next's own compiled tracer: **64 files · 9.2 MB** (−887 files · −107.85 MB). Every admitted path resolves to the same file as before; a non-seed path is refused outright rather than sliced. Estimated function size after: ~144 MB (252.37 − 107.85), ~105 MB of headroom.
- **Guard.** `lib/no-server-file-carries-public.test.ts` derives every server file that builds a path from `process.cwd()` (13 today), traces each alone with Next's tracer, and fails if any carries `public/` outside `ALLOWED_PUBLIC` or more than 20 MB. Mutations, each counted and each RED: root back at `public/` (887 files · 107.85 MB flagged) · a new stray reader of `public/demo` (28.27 MB flagged) · tracer ignoring everything (anti-vacuity) · walker finding nothing (floor). A behavioural mutation (seed path off by one) turns 3 of the 68 decor-layer tests RED; the fix keeps all 68 green.
- **Shared bundle ceiling 201KB → 202KB**, by the measured amount: #5397 changes only the `next` version and lockfile, and the shared bundle grew 200.5 → 201.5KB inside Next's own runtime chunks (+0.9 app-router, +0.2 pages main).
