## 2026-11-14 · feat(admin): ASK-KW / ASK-BRAIN slice 1 — the ⌘K box turns plain words into one recommended action, is held to a phrase bank, and learns from picks

Owner, 14 Nov 2026: *"What if i said add a new service in the catalog. or create a new promo. or change a pricelist"* · *"find keywords to my statement to give me a recommended action"* · *"create a brain that also learns"* · ruling *"let us start with plain words and learning"*.

- **Keyword table** (`lib/admin-map/ask-keywords.ts`): verbs → intent (create · edit · open · remove · decide, English + Taglish), nouns → place + the job that does it. When a sentence has both, the box's FIRST row is one **Recommended** action ("Add a service → … › Categories & event types"), then that page, then the rest; ↵ takes it. It opens a page or prepares a form — it never saves, publishes, changes a price or confirms. "pricelist", "catalouge", "promocode" and friends are mended before ranking, so they are never "a word no page has".
- **Phrase bank** (`ask-phrase-bank.generated.ts`, `pnpm admin:phrases`): 1,675 phrases generated from every menu page, every form job and the keyword table, each with its expected first row. **Simulator** (`ask-phrase-bank.test.ts`) runs every phrase through the shipped box: top-1 accuracy **64.1 % → 100 %**, floor 99.5 %, misses printed.
- **Learns**: opening a result records phrase → place through the existing admin-gated `askTheAdmin` (new optional `learn` argument — no new server action) into `admin_search_phrases` (`learned_from='admin'`, `times_used`, `last_used_at`). Next time it is first, marked "You picked this before", with "Forget this". Most-used wins on the one row per phrase (`learnPick`). No migration.
- One ranking function (`palette-rank.ts`) is shared by the box, the bank and the guards; the scorer moved to `palette-score.ts` (bands unchanged); `priceRowFor` is shared by the row reader and the guards.
- "What can I ask?" shows the four pinned sentences in the empty box.

SPEC IMPACT: None in this slice — site-wide search, per-role learning (an ADD-only migration) and offline search are slice 2, held for the owner's OK on the prototype (`build-sessions/prototypes/ask_brain_site_wide_2026-11-14.html`).
