# Rules whose animation keeps a TRANSFORM applied after it ends (fill-mode
# both/forwards over keyframes that touch transform/translate/rotate/scale).
#
# WHY THIS LIST EXISTS — measured on production 2026-09-18. `.sn-page-enter`,
# the wrapper around every in-shell page, ended on an IDENTITY transform
# (matrix(1,0,0,1,0,0)). It moves nothing and is invisible in a screenshot, a
# diff and a review. Per CSS spec any transform on an ancestor becomes the
# containing block for `position: fixed` descendants — so it silently unpinned
# every fixed overlay in the app. The vendor coach-mark measured 636x2444
# against a 1107px viewport; its Skip and Next buttons sat 341px below the fold.
#
# Most entries below are LEAF elements (badges, loaders, decorative spans) where
# a held transform harms nothing. They are listed, not fixed, because "harmless"
# depends on whether anything inside is position:fixed — a fact about the React
# tree, not this stylesheet.
#
# THE LIST MAY ONLY SHRINK. A new entry fails the guard: prove nothing fixed
# lives inside, then add it here with a reason, or use `backwards`.
#
# `.sn-page-enter` is deliberately ABSENT and must stay absent.

# The Event Hub canvas's background photo layer (owner 2026-09-23). It is a
# SELF-CLOSING, CHILDLESS div — `<div aria-hidden className="hub-canvas-media" />`
# in app/[slug]/_components/hub-canvas-frame.tsx — so it has no descendants at
# all and can never be the containing block for a position:fixed one. The held
# transform is also load-bearing rather than incidental: the couple's zoom is
# composed INTO the keyframes (`scale(var(--hub-zoom))`), because an animation
# replaces the whole transform, so `backwards` instead of `both` would drop the
# zoom the moment the scroll range ended and the photo would jump back to 1x.
# `a-section-background-is-a-ref.test.ts` holds the childless shape — in the
# source AND in the rendered DOM — so this entry's reason cannot quietly rot.
