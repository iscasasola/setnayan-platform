## 2026-11-12 · feat(discover): Find suppliers lives inside Discover — the supplier view on `/`

- **One pipeline.** `/explore`'s data loading and results moved, unchanged, from `app/(shell)/explore/page.tsx` to `app/(shell)/explore/_lib/marketplace-view.tsx` (`MarketplaceView({ raw, surface })`). The category list moved to `lib/marketplace-category-options.ts` and the faith lookups to `lib/marketplace-faith-options.ts`. Every guard that scanned the old page now scans the moved code.
- **The supplier view on `/`.** A supplier parameter (`category`, `folder`, `tile`, `city`, `sort`, `page`, `verified`, `match`, `offseason`, `event_type`, `faith`, `venue`, `lens`, `from`, `browse`) swaps Discover's shelves for the supplier view, the same way a search already does (`lib/discover-suppliers.ts`). It has [All categories ▾] [Sort ▾] [Filters], one summary line with "Clear all filters", and the compare line. Sort is one dropdown (PickMenu); Off-season savings is a switch inside Filters. The plain `/` does not load the pipeline.
- **One search box.** With no supplier parameter, `q` is Discover's own search. With one, the top bar's box carries the view's parameters, so `q` narrows the suppliers. "Narrow these results…" is not drawn on `/`.
- **The Shops shelf** gains "All categories ▾" and "Filters", plus "See all suppliers →" once more shops are open than it shows. The category sheet and the filter sheet load on the first press.
- **Retired: the Find suppliers page and row.** The signed-out rail is four rows: Discover · For suppliers · For coordinators · Features (then Sign in). `/explore` forwards permanently (308) to `/` with every parameter carried — `notice` alone is dropped — through `lib/legacy-redirects.ts`, so in-event `?folder=…&from=plan` links keep their plan context. A bare `/explore` is Discover itself. `/vendors/*` forwards along the same path; `/explore/compare` stays where it is. Public doors (about, marketplace, realstories, the `/suppliers` landings, the blog, the footer, not-found, waitlist, admin demo links) now open `/?browse=1`. Admin and supplier saves refresh `/` instead of `/explore`. Sitemap, robots and llms.txt drop `/explore`; the search action is `/?q=`.
