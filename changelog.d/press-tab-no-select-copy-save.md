## 2026-11-27 · fix(L3): links press, Tab goes box to box, no text selection, Copy and Save where people need them

Lane OLD-L3 (MASTER-PLAN-2026-11-27 L3 · A1 · A2 · A3 · A9; owner rulings R1 + R5, DECISION_LOG 2026-11-27 "No text highlighting or copying app-wide").

- **Press feedback on links (A9).** `PRESS_TARGETS` (`app/_components/press-feel.tsx`) and its CSS twin in `globals.css` now name `a[href]`: the bottom nav, header icons, Unihome chips, Event Home tiles and supplier Today tiles dip like buttons. Inline text links are not transformable, so they never move. A see-through door over a card (`.hc-door`) hands the press to the card under it. The guest Event Hub (`.sn-editorial`) is unchanged.
- **Sign-in Tab order (A1).** The password eye (`password-field.tsx`) is `tabIndex={-1}`; its name, `aria-pressed` and `aria-controls` stay. The app-wide ✕ that appears in a type box while typing (`GlobalClearField`) is not a Tab stop either — on /login and /signup it sat between Email and Password. Walked in a browser: Tab now runs Email → Password → Stay signed in → the button, plain and Gmail addresses alike.
- **No text selection app-wide (R1, /admin included per R5).** `body` takes `user-select` and the long-press callout off; inputs, textareas, selects, editors (`[contenteditable]`) and `[data-selectable]` stay selectable, with the explicit `-webkit-user-select: text` iOS needs. Chat message words wear `data-selectable` (the one stream every role reads, plus the decision panel and the arrival thread). `CopyButton` now shows the value in a selectable box when the clipboard is blocked.
- **Copy buttons:** receipt number (every receipt page, screen-only), error references (root, Event Hub, supplier, admin "Copy error"), off-platform supplier contact (service workspace), admin verify email/phone, admin shop contact, admin user email, venue address (supplier client view, the couple's booked venue card), proposal account number, admin payments order ID / ref / payment ref.
- **Save buttons:** every `PhotoViewer` without its own Share gets a Save (mood board, supplier collections, shop photo menu); the guest's own Papic shot viewer; the crew QR (`event-qr`); payment QRs on proposals, supplier direct pay and the couple's own pay ways. Save-failure lines no longer tell people to press and hold.
- **One save in event settings (L3).** In the ⚙ sheet, the basics (`DetailsForm`) and the pricing view (`PaxSettingsCard`) save on their own (a pause after a change; a pick at once), quietly, with "Saving…" / "Saved" and a refusal said in words; the sheet's one button is the Hub's Apply ✓. Event Details' own page keeps its buttons. The two-host merge guard rides along on every save.
- **One Tab stop per control (A2).** An uploader's hidden file input leaves the Tab order where a visible button opens the picker (`file-upload.tsx`). The pin map's Zoom +/− and © link are not Tab stops (the map pans and zooms from the keyboard). Leaflet maps (shop service editor, open-shop city pin) drop their corner links from the Tab order (`lib/map-controls-leave-tab-order.ts`). `ActionButton` takes `tabIndex={-1}`.

Guards: new `lib/no-text-selection-app-wide.test.ts`, `lib/event-settings-has-one-save.test.ts`, `lib/where-people-copy-there-is-a-button.test.ts`, `lib/one-tab-stop-per-control.test.ts`; extended `lib/the-press-feels-the-same-everywhere.test.ts` (`a[href]`, the card door) and `lib/one-password-field.test.ts` (the eye is not a Tab stop).
