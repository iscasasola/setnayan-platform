Press ✕, “Not now”, or the dimmed page to close. No script — a checkbox and a label.

What this costs, stated plainly. Points 01, 03 and 07 override overview_FINAL, your_team_FINAL and guestlist-v2 — three drawings you approved, all built on the bordered rows this brief bans. You chose the whole dashboard knowing that; it is recorded here so no later session reads it as drift.

What it does not touch. The five rooms, one roster on both navigators in every moment, the dissolved “Also in this event” drawer, and the Everything index — those are structure, and this brief is a skin. The three link-fixes (Sponsors, Alaala, Manpower) still land with the IA change.

Zero JavaScript, deliberately. The viewport simulator, the tooltips, the inspector and every press state are CSS — radios, labels, :hover, :focus-within, :checked. It works in a viewer that refuses script, which a JS build would not.
