## 2026-11-23 · feat(themes): Event Hub themes redraw, part 1 — still pictures + five new Pro themes (batch 1) [migration]

Owner 23 Nov: DECISION_LOG "EVENT HUB THEMES ROUND 2 — YES, THIS LEVEL" (*"one real still picture per theme"*, never
video), then "BATCH 6 APPROVED" (all 53 approved). Sheet: `prototypes/maker_themes_redraw_2026-11-23/batch1/`.

- **New Pro themes in the one registry** (`lib/invite-themes.ts`): Perlas, Waling-waling, Capiz, Hagdan and Solihiya.
  Each theme's colours (canvas, surface, ink, muted, accent, heading) and its two faces are copied from the sheet.
- **Still themes:** `HubThemeMedia.loop` may now be `null`.
  - The theme's poster is then its whole background (`artFor` → `r2://setnayan-media/theme-art/2026-11-23/<id>.webp`).
  - The guest page already draws a poster when there is no loop.
  - The readability check measures the shade over each picture's lightest and darkest 5 %.
- **Order:** free themes first, then Pro by file size (the owner's "based on size" rule). The stills are lighter than
  every loop, so they come right after the free three.
- **Capiz is live again.** Saved `capiz` is no longer read as Vintage; the one event that saved it now shows the new
  Capiz.
- **Every surface gets the new themes:**
  - a page block per theme, generated by `hubThemePageTokens`, in the new `app/hub-themes.css`. `globals.css` is parsed
    by every page and sits at its ceiling, so the redraw's blocks load only where a theme is worn: the guest Event Hub
    (`app/[slug]/layout.tsx`) and the event's own pages, the Maker among them (`app/dashboard/[eventId]/layout.tsx`);
  - die-cut, spot layers, still placement and print type in `lib/print-pieces.ts`;
  - the reveal's materials in `lib/reveal-materials.ts`;
  - the invitation door, through the existing compositions.
- **Faces:** six new self-hosted faces, never preloaded: Raleway, Gloock, Mulish, Work Sans, Epilogue and Newsreader
  (`scripts/build-theme-faces.py --only=…`).
  - Italiana and Marcellus already shipped and are reused.
  - Each new face is in the Maker's font dropdown, with its outline for the Logo and the prints
    (`scripts/make-logo-outline-fonts.py --only=…`).
  - The "Most used" fonts list is re-counted with the new themes.
- **Migration** `20271360404554_the_batch_one_event_hub_themes_can_be_saved`:
  - widens `events_invite_theme_check` to the five new ids;
  - widens `events_site_font_key_check` to the six new faces;
  - only widens, so no saved row can fail it.
- **Art:** the eight batch 1 pictures are in the specs corpus `assets/theme-art-2026-11-23/`. An admin uploads them
  with `scripts/upload-theme-loops-to-r2.ts --apply`, which now handles still themes. Until then a theme shows on its
  plain background colour.

- **Prints fit:** the landscape event card (5 × 3) fits its words one safe margin in from each side; a line set at
  the full column width in the new faces ended 0.3 pt past the safe line.
