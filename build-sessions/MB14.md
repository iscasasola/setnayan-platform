# MB14 — The decor-image pilot goes live

**Goal:** the 10 generated images sitting in `scratchpad/decor-pilot/` reach couples.

**Model:** Sonnet · medium effort — mechanical upload and tagging against an existing recolor
engine. The fallback invariant is the only sharp edge.
**Size:** half-day. **Depends on:** **R2 credentials — and nothing else.** Slot it anywhere.

## 🛑 Owner provides

R2 credentials. The images are generated and waiting; the migration is deliberately inert at
`approved_at = NULL` so nothing appears until this session flips it.

## Delivers

- Upload the 10 images to R2
- Tag `moodboard_asset_color_ranges` via programmatic dominant-colour sampling
- Flip `approved_at` from `NULL`
- **Composite-with-fallback** in `reception-scene.ts` — any uncovered `(zone, style)` combination
  stays **byte-identical flat SVG**

## The one sharp edge

The fallback is the whole safety property. A couple whose zone/style combination has no photo must
see exactly what they see today — not a blank, not a substitute, not a near-miss image of someone
else's wedding.

- **byte-compare the fallback render for uncovered combos before/after** — the e2e before/after
  PNGs in the pilot folder show the intended technique
