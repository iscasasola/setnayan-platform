What changes

  • A tap on an organiser’s card opens the menu. It no longer goes straight to the Dashboard.
  • Phone: the house Sheet with a grabber. Desktop: a small anchored menu. One backdrop that dims and blurs; the page behind cannot be pressed.
  • Open Dashboard is the one filled row. Delete Event is last, in red, under a divider.
  • Keyboard: Enter opens, Tab stays inside, arrows move, Esc closes and focus returns to the card.

What it removes

  • The Dashboard · Event Hub · trash buttons under each Home card (Unihome v5, approved 23 Nov).
  • One-tap entry to the Dashboard from the picture or name. It is now two taps.
  • “Put this away” as the first screen of the trash icon. It stays, inside Delete step 1.

Rules used

  • Publish Story opens the day after the event (the app’s story gate). It is free, not a paid lock.
  • The row is a door to the Story’s publish step. Publishing still needs a clear desk and the consent tick there.
  • Open your Event Hub opens the hub page itself, signed in as you, the way your own QR opens it. It only shows the hub. A signed-in organiser gets in even while the hub is private, so the row has no lock.
  • Open Chat and Open your Memories carry no lock for an organiser: neither page waits for the event date or a plan.
  • Delete keeps today’s flow: what goes, put-away first, optional reason, then the typed name.
  • Guests get no menu. Helpers are not drawn. A booked coordinator is kept out of Memories today, and a limited helper reads Chat but cannot start one unless given Suppliers.
