# Gown maker assets

## female.glb

- **What:** the faceless mannequin the gown maker dresses (one skinned body, 10,418 vertices, 105 bones).
- **Source:** base mesh by Innerscene Corp (innerscene.com), released under **CC0 1.0** (public domain dedication).
  Stylised as a faceless mannequin and decimated for Setnayan. The same credit is in the file's own glTF `asset.copyright`.
- **Taken from:** the approved prototype, corpus `prototypes/gown_maker_2026-11-27/mannequin/female.json` (the GLB was
  stored there as base64; it is unchanged here, byte for byte).
- **Women only:** the prototype's men's body (`male.json`) is not part of the platform.
