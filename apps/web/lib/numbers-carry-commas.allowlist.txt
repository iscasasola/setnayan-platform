# numbers-carry-commas.allowlist.txt — the ONLY raw renders the sweep in
# `numbers-carry-commas.test.ts` accepts. One row exempts ONE finding.
#
#   <path under apps/web> :: <expression, whitespace-collapsed> :: <why it is not a raw quantity>
#
# Three honest reasons exist, and every row must be one of them:
#   TEXT        the value is ALREADY a string (grouped upstream, or copy), and
#               the scanner cannot see a property's type.
#   IDENTIFIER  the digits are something a person or system must match exactly
#               (a typed confirmation, a diagnostic value), not a quantity.
#   BOUNDED     a figure that cannot reach 1,000 by construction, whose exact
#               precision matters more than any shared formatter offers.
# A row that no longer matches a finding FAILS the test — delete it.
