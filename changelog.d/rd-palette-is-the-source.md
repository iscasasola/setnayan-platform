## 2026-10-05 · fix(theme): the Mood Board palette dresses every theme — tiles, previews and prints agree; no palette → the theme fills it

Owner, 2026-10-05 (DECISION_LOG "THE MOOD BOARD PALETTE IS THE PRIORITY"): *"The priority palette will always be based on the mood board. If the mood board does not have a palette, use our original theme and place it on the moodboard's palette. If a moodboard has a color palette already then all themes will adapt to the color palette of the moodboard."*

- **One resolver** — `lib/theme-colours.ts`: `paletteColourVars` (the guest page's `--color-*` vars, used by `guestLookFrom`) and `themeColours` (the same answer as hexes, for pictures). Three cases: no palette → the theme's own colours; a theme's SEED → that theme's own colours (so Cyber Neon picked on an empty board stays dark, and every other theme wears it); any other board → the Mood Board derivation the guest page always wore, unchanged.
- **Maker scene tiles**: the words-only tile tint (`website/editor/page.tsx` → `SceneMiniature`) reads the resolver with the drafted board. maria-and-jose (light board, Cyber Neon drafted) drew every tile dark under a light canvas; the tiles now agree. No change in `editor-shell.tsx`.
- **Prints**: `printLookFor` takes the resolver's answer (`loadPrintSet` asks it with the event's board, drafted over live); a palette-dressed print over a full still is veiled in the palette's paper.
- **Theme gallery** ("All themes" + the full-screen preview + the sample prints): the sample Event Hub and its prints wear the couple's board (`?palette=` on the sample row / sample print door only — colours, nothing else), or `none` (each theme's own colours) when the board is empty.
- **Save-the-Date film**: an unpicked film background is the theme's paper as the board dresses it.
- **No palette → the pick fills it**: `role_palette` joins the hub draft as a look column, accepting only a theme's seed (`sanitizeSeedPalette`), only onto an EMPTY board (a painted board is never overlaid, counted or applied), never cleared from the draft. The picker drafts it in the same patch as the theme (one Undo); Apply lists it as "Mood Board · Colours from <theme>". Opening anything writes nothing.
- Guard: `lib/a-theme-preview-wears-the-palette.test.ts` (behaviour on maria-and-jose's real board + wiring + a sweep of the Maker, guest components and print door for theme colours read around the resolver). Sabotaged 4 ways — tile tint back to the theme palette, a gallery print without the palette, a seed read as a generic board, print paper from the theme — each red; restored green.
