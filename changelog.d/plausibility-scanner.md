## 2026-07-24 · feat(integrity): deterministic price-under-declaration plausibility scanner (dark)

A SECOND-layer, admin-only integrity signal that flags a couple-confirmed LOCK whose declared `event_vendors.total_cost_php` is implausibly low. Couple-confirmation stays the load-bearing anchor on the price; this is a cheap deterministic triage aid to catch the lazy under-declarer and shrink the admin queue. **NO LLM, ₱0/run** (Setnayan AI Rule 1). Ships **DARK** behind `NEXT_PUBLIC_PLAUSIBILITY_SCANNER_ENABLED` (default OFF) — no couple-, vendor-, or admin-facing change until flipped.

**Three deterministic tiers** (pure, tested math in `lib/plausibility-scoring.ts`; server I/O in `lib/plausibility-scanner.ts`):
1. **Inclusion cost-floor** (self-referential) — the lock vs Σ of the vendor's OWN declared inclusion "worth ₱" (`vendor_service_inclusions.worth_php`, resolved via the linked listing). ⚠ DATA GAP: `worth_php` is a vendor-stated MARKETING value, not audited cost — so the trigger ratio is deliberately harsh (lock < 33% of stated worth) to discount puffery. Built the mechanism + noted the gap in the module docs.
2. **Category×location median** (cross-vendor) — the lock vs `market_price_bands` LOW for its category×region (reuses `lib/price-position.ts` region/pax-bucket resolution). **COMPETITION-LAW guard:** the ONLY cross-vendor tier, capped (`TIER2_WEIGHT·100 = 35 < FLAG_THRESHOLD 50`) so it can NEVER flag a vendor on its own for being cheaper than peers — it only corroborates. INTERNAL admin signal only; no couple/vendor "below market" copy anywhere (unit-tested).
3. **Self-consistency** (self-referential, strongest) — the lock vs the vendor's OWN verified median across their OTHER same-category locks (reuses `computeVerifiedMedian` from `lib/verified-median.ts`). A >60% discount off their own median flags; the subject lock is excluded from its own reference. Below the min-sample floor → no flag.

**How honest budget vendors are protected:** tiers 1 & 3 compare a vendor only to their OWN promise / OWN typical price, so a uniformly-cheap-but-honest vendor is internally consistent and never fires. The one cross-vendor tier is capped below the flag threshold. Everything is detect-and-review — NO automated penalty; a human dismisses false positives and a dismissed flag stays dismissed.

**Surface** — reuses the existing `/admin/integrity-watch` queue (`integrity_flags`) via a new `kind='price_underdeclaration'` + a flag-gated "Prices" tab with a "Rescan prices" action. Migration `20270929100000` widens the `kind` + shape CHECKs and adds a nullable `subject_event_vendor_id` (FK → `event_vendors`, dedup partial-unique index) — inert on its own (a nullable column + wider CHECK create zero rows), RLS unchanged (admin-only, service-role writes). Resolution is dismiss / confirm (verdict only — never adjusts the price or penalizes the vendor).
