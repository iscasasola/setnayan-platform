HOW TO MEASURE HONESTLY — every one of these has cost this programme real time:

  · 🔑 **PRINT ELAPSED TIME BESIDE EVERY EXIT CODE.** `timeout` **does not exist on macOS**; it
    returns **127 in zero seconds**, which reads exactly like a fast decisive pass. Duration is

    from "it ran and failed".
