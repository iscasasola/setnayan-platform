🔴 THE DERIVATION TRAP — THE WHOLE REASON THIS IS AN OPUS SESSION.
The 20% must be COMPUTED AS HALF THE ROW'S OWN IMPLIED SIGN-UP DISCOUNT:

    SETNAYAN_AI    ₱2,499 / ₱1,499   saving ₱1,000  half ₱500  →  ₱1,999

display-vs-money-path divergence to police. A screen saying "20% off" is display-layer rounding
of a number the money path never uses.
